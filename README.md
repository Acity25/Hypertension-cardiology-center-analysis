Hypertension Cardiology Analysis

Objective

Analyze hypertension patient data to identify predictors of BP control failure and evaluate antihypertensive drug effectiveness.

Dataset

* 350 Patients
* 16 Variables

Tools Used

* Excel
* Power BI
* DAX

Key Insights

* BP control rate was 9.43%.
* Medication adherence strongly influenced BP control outcomes.
* Patients with CKD showed poorer BP control.
* Drug effectiveness varied across comorbidity profiles.

Dashboard Features

* KPI Cards
* BP Control Analysis
* Medication Adherence Analysis
* Age Distribution
* CKD Analysis
* Drug Class Performance
